# Social

Ready-made social images built from the Aleem AIUX logo, with no live text, so they stay sharp wherever they're posted.

- `aleem-avatar-800.png`: profile picture, 800×800. The mark on a full-bleed navy square. It crops cleanly to a circle.
- `aleem-og-image-1200x630.png`: link preview (Open Graph and Twitter card). The primary logo on Night `#06121F`, with the pill pattern and a cyan glow.
- `aleem-linkedin-banner-1584x396.png`: LinkedIn cover on Cloud `#F4F5FA`. The primary logo sits on the right, clear of the profile photo at the lower left.
- `aleem-x-header-1500x500.png`: X / Twitter header on Night, logo on the right.

To make a variant, keep the logo files as they are and follow `assets/Logo/README.md`.
