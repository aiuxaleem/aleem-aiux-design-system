# LinkedIn caption: Figma Agent, context-aware intelligence on the canvas (v2)

Figma Agent is not a chatbot beside the canvas. It is an agent that reads the canvas and builds on it with your team.

Four things stood out to me at Figma Config 2026:

1. Deep canvas integration. The agent is embedded across the Figma canvas to automate repetitive manual tasks, assemble screens using component libraries, and scaffold layouts automatically.

2. Transparent team collaboration. Agent chats are visible to teammates by default, so collaborators learn from each other's prompt strategies and build on previous explorations. Private chats are one toggle away.

3. Skills, Connectors and context. Teams package workflow rules and conventions into reusable Skills, attach research briefs or artifacts to guide the agent, and connect live tools (Notion, Slack, Granola, GitHub, Atlassian, Hex) to pull product data and documentation onto the canvas.

4. Expansion across surfaces. Dedicated agents are coming to FigJam (parse codebases into visual diagrams and organized ideas) and Figma Slides (draft full decks from raw concepts).
