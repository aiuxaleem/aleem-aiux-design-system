# LinkedIn caption: Code layers bento

Figma just made code a native design material.

Not a handoff. Not a plugin. Live, editable code sitting on the canvas next to your frames. I spent a week with code layers and four things stood out.

1. Interactive code on the canvas
Convert any design layer into an interactive code layer with one click or a prompt. Then explore several functional directions side by side, the way we already compare visual directions.

2. Editing works in both directions
Extract Designs pulls frames out of a code layer as editable design layers. You tweak visuals, motion or copy in the tool you know, then Update Code Layer syncs those changes straight back into the code. No "can you update the build" message.

3. Four ways to create one
Prompt the Figma Agent. Hand it to an external coding agent through the Figma MCP. Clone a GitHub repository. Or capture a live web page with Capture Code in the Chrome extension.

4. Developer controls and parallel agents
Every code layer opens a full-screen editor with a file viewer, Git commit diffs and an active terminal sandbox. Several agent chats run inside one layer at the same time, each on its own task.

My take: the design file is becoming the place where the product actually runs. The gap between "looks right" and "works" just got a lot smaller, and the designers who can read a diff and write a precise prompt will set the pace.
