# LinkedIn caption: Traditional UX vs AI UX

I spent ten years learning to design software that does the same thing every time. Then I started designing for a model, and half of those habits stopped working.

Six places where it breaks:

1. System logic. Traditional UX is predictable. AI UX is confidence-based. If the system is 92% sure, the interface has to say so, and design for the other 8%.

2. Interface. One fixed layout for everyone becomes a layout that assembles itself per user. You stop drawing screens and start writing the rules that generate them.

3. Control. Clicks and wizard steps become override paths. Every AI action needs a clear way to say "no, do it my way" and a drop to manual.

4. Errors. Fixed fallbacks become graceful ambiguity. "I am not sure, here are two readings" is a valid state now, and it needs a design.

5. Trust. Visual consistency still matters, but trust now comes from explainability. "Why this?" is a core component, not a tooltip.

6. Testing. Static clickable mockups cannot show you any of the above. You test live, against real model behavior, with real inputs.

My read: the craft did not get easier, it moved. Less time on pixel-perfect fixed screens, more time on confidence, limits and recovery.

Which of the six is hardest for your team right now?
