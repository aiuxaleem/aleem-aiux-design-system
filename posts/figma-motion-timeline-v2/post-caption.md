Figma Motion puts a real timeline next to your frames. Keyframes, easing curves and timing live where the design lives, then flow into tokens, Dev Mode and code.

Core canvas and AI capabilities

1. Native timeline and keyframe animation. Designers gain direct access to full timeline animation tools on the canvas, complete with customizable easing curves, keyframes and presets, or can prompt the Figma Agent to generate starting motion patterns.

2. Motion as a foundational design token. Motion curves integrate directly into design systems. Animate a master component once and the interaction timing propagates across every connected file and screen.

Handoff, code and export ecosystem

3. Production Dev Mode handoff. Engineers inspect precise keyframes and timing curves in Dev Mode without ambiguity, then copy production-ready code in CSS, JSON or React.

4. MCP compatibility and multi-format export. Animation physics pass directly to coding agents via the Figma MCP, with direct exports to MP4, WebM, Animated SVG and GIF.
